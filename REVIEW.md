## Contradictions found (FACT)

### C-1 — Stale stack versions in `CLAUDE.md` vs ground truth (`app/package.json`)

`CLAUDE.md` "Tech stack" table lists older major versions than what is actually installed:

| Item | `CLAUDE.md` says | `app/package.json` (truth) |
|---|---|---|
| Vite | 7 | **^8.3.0** |
| TypeScript | 5.9 | **~7.0.2** |
| Framer Motion | 12 | **^13.2.0** |

`ARCHITECTURE.md` matches the truth (Vite 8, TS ~7.0.2, Framer Motion 13). **CLAUDE.md is
the stale document.** Its "known issues" note ("Framer Motion 12 requires React 18+ —
confirm compatibility with React 19") is also obsolete (FM 13 + React 19 are the installed
pair). *Recommendation for owner:* refresh the `CLAUDE.md` version table (not changed here
because the file carries a managed standards block and version edits are the owner's call).

### C-2 — Dual lockfiles vs "pnpm only" standard

The chrysa standard states: *"The JS/TS package manager is `pnpm` — `npm` and `yarn` are
forbidden."* Yet `app/` contains **both** `pnpm-lock.yaml` (137 KB) **and**
`package-lock.json` (182 KB), and there is no `packageManager` field in `package.json`.
Two lockfiles can drift. *Recommendation:* pick pnpm, delete `package-lock.json`, and pin
`packageManager`. **[FACT — both files present. Not fixed: dependency/config change is out
of scope for a docs pass.]**

## Documentation debt (INFERENCE)

1. **`AskMeWidget` runtime is undocumented.** No doc states whether the "AI Ask Me" widget
   calls an external LLM at runtime or answers purely from bundled `cv.json`. This matters
   for both security (embedded key?) and offline behaviour. Owner should document it.
   **[UNKNOWN]**
2. **MSW not confirmed.** Standard asks for MSW in the frontend test setup; presence not
   verified (demo fixtures may fill the role). See TESTING.md. **[UNKNOWN]**
3. **E2E scenario coverage undocumented.** Playwright specs exist (`app/tests/`) but the
   scenarios they cover are not listed anywhere. A short index would help. **[INFERENCE]**
4. **`cv.json` has no schema.** `CLAUDE.md` already flags this ("schema is informal — no
   JSON Schema validation yet"). Still open. **[FACT — owner-acknowledged debt]**
5. **Many generated context files** (`context.md`, `llms-full.txt`, `handover.md`,
   `guideline-report.html`) are regenerated by `scripts/gen_context_files.py` — editing
   them by hand is a trap; they carry a "do not edit" banner. Documented here so a future
   contributor does not hand-edit them. **[FACT]**
